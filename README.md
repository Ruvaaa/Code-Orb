# Code Orb

Code Orb is an animated, frame-based companion in a dedicated VS Code Activity Bar container. It uses local PNG artwork, reacts to editor activity, follows the mouse, and respects VS Code theme and motion preferences.

## Use

Open Code Orb in the built-in Explorer sidebar. VS Code usually places contributed Explorer views at the bottom below Outline and Timeline; if needed, drag Code Orb directly below VS Code Pets. VS Code remembers its position. Press F5 to launch an Extension Development Host during development.

## Commands

- Code Orb: Poke
- Code Orb: Sleep
- Code Orb: Wake
- Code Orb: Celebrate

## Settings

- `codeorb.enabled`
- `codeorb.size`
- `codeorb.reduceMotion`
- `codeorb.reactToTyping`
- `codeorb.idleBehaviors`

## Package

Run `npm run package:vsix` to create a VSIX.
